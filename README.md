# Adarsh Karmic - Creative Engineer & Serverless Architect

Welcome to the source code of my personal portfolio. This project showcases my expertise in building high-performance, immersive web experiences by combining cutting-edge 3D frontends with infinitely scalable serverless architectures.

🔗 **Live Portfolio:** [adarshkarmic.vercel.app](https://adarshkarmic.vercel.app)

## 🚀 Tech Stack & Core Technologies

This portfolio is built with a focus on modern web standards, smooth animations, and premium aesthetics.

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** Custom CSS, SCSS & [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://gsap.com/) & [Lenis](https://lenis.studiofreight.com/) for buttery smooth scrolling
- **3D & WebGL:** [Three.js](https://threejs.org/) & [Spline](https://spline.design/) (via `@react-three/fiber`)
- **Deployment:** [Vercel](https://vercel.com) Edge Network

## ⚡ Key Features

- **Interactive 3D Elements:** Background parallax glowing orbs and deep visual immersion.
- **Buttery Smooth Scroll:** Engineered with Lenis to override native scrolling for a premium feel.
- **Live Project Previews:** Real-time iframe scaling to showcase active client websites directly within the portfolio cards.
- **Fully Responsive:** Meticulously crafted for Mobile, Tablet, and Desktop layouts.

## 🛠️ Local Development

To run this project locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
